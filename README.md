# Portfolio + Blog

A simple personal portfolio and blog website built with plain HTML, CSS and JavaScript. No backend - all data (blog posts and registered users) is saved in the browser using localStorage.

## Pages

- `index.html` - Home (About Me, Skills, Projects)
- `about.html` - About / Contact
- `blog.html` - Blog post list
- `write.html` - Write a new post (login required)
- `post.html` - View a single post
- `register.html` - Create an account
- `login.html` - Login

## How to run

Just open `index.html` in a browser. No installation or server needed.

## Tech used

HTML, CSS, JavaScript, localStorage
